# Changelog

## 1.0.0 - 2026-10-29

- Magento 2 hosted checkout with store-view configuration and encrypted API/IPN credentials.
- Durable invoice creation/retries, signed IPN plus authoritative API verification, and exact order/currency matching.
- Native paid invoice/capture registration, duplicate protection, atomic journal writes and conservative exception handling.
- Payment details in Magento orders, scheduled reconciliation and `whollycrypto:reconcile`.
- Isolated public PHP SDK 2.7.0, install ZIP/checksums and staging documentation.
